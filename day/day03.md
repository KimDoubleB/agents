토큰 비용
- Input 토큰: 사용자가 모델에 입력하는 텍스트를 토큰 단위로 분해한 것. 예를 들어, 질문이나 프롬프트가 이에 해당합니다.
- Output 토큰: 모델이 생성하는 응답 텍스트를 토큰 단위로 분해한 것.
- 출력 토큰 생성은 모델이 예측하고 생성하는 과정이므로, 계산량과 리소스 소모가 더 크고 비용이 높게 책정되는 경우가 많습니다.
- 입력 토큰은 단순히 모델에 주어지는 정보로, 출력 토큰보다 비용이 상대적으로 낮게 책정되는 경우가 많습니다.

OpenAi library에서 base_url을 변경할 수 있는데, 만약 사용하고자 하는 모델이 OpenAI 인터페이스를 지원한다면 모델에 맞는 라이브러리를 사용하지 않아도 OpenAI 라이브러리로 활용할 수 있다.
- 예를 들어, gemini가 그렇다. `https://generativelanguage.googleapis.com/v1beta/openai/` endpoint를 제공함
